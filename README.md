# MJ's Kitchen

Homemade baby food that grows with her: recipes by texture stage (6 months to 12+), a daily meal log, what's next suggestions, a freezer list with dates made, a batch-cooking planner, and a reaction log.

Live site: https://djsminimart.github.io/MJ-s-Kitchen/

Everything you log is saved in your phone's browser; use Log > Save a backup now and then.
