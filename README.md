# MJ's Kitchen

Homemade food from first purees to age 5: recipes by stage (6 months to 5 years), a daily meal log, what's next suggestions, a fridge and freezer list with use-by dates, a batch-cooking planner, and a reaction log.

Live site: https://djsminimart.github.io/MJ-s-Kitchen/

Everything you log is saved in your phone's browser; use Log > Save a backup now and then.
